# Один userscript для Chrome, Яндекс.Браузера и Firefox

Начиная с **0.12.0** используется один `dist/ZakvielMarket.user.js` для актуальных настольных Google Chrome, Яндекс.Браузера и Mozilla Firefox с Tampermonkey. Отдельные сборки и выбор браузера в настройках не требуются. Android/iOS и другие менеджеры userscript не входят в проверенную конфигурацию.

## Установка

| Браузер | Что установить/разрешить |
|---|---|
| Google Chrome | Установить Tampermonkey через [официальный сайт](https://www.tampermonkey.net/). В деталях расширения на `chrome://extensions` разрешить пользовательские скрипты, если браузер показывает этот переключатель. |
| Яндекс.Браузер | Установить Tampermonkey из совместимого каталога Chrome/Opera. Управление расширениями — `browser://extensions`. Разрешить userscript, если такая настройка доступна. Защитные настройки браузера должны разрешать установленный менеджер. |
| Mozilla Firefox | Установить Firefox-версию Tampermonkey через официальный сайт. Сохранить стандартный режим исполнения скрипта: `@sandbox JavaScript` указан в самом userscript. |

Во всех трёх браузерах импортировать **тот же файл** через Tampermonkey → «Утилиты» либо создать скрипт и заменить его текст содержимым файла. После обновления полностью перезагрузить игру: перехватчики уже открытой страницы остаются до перезагрузки. Затем нажать ⚙ в свёрнутом HUD, войти в аккаунт сайта и включить сбор.

Локальный сервер по-прежнему должен работать на `http://127.0.0.1:4173`. Настройки и вход хранятся отдельно в каждом браузере; серверные контакты и данные доступны через тот же аккаунт. Один userscript не устанавливается как нативное расширение Chrome/Firefox — ему нужен Tampermonkey.

## Как выбирается режим

- Проверяются доступные функции, без ветвления по User-Agent и без передачи сведений о браузере на сервер.
- Если доступен Firefox `exportFunction`, используются экспортированные обработчики и Promise/ошибки страницы. Chrome и Яндекс используют обычный режим того же кода.
- Для отсутствующих `AbortSignal.timeout`, `signal.throwIfAborted` и `crypto.randomUUID` есть локальные совместимые реализации. Существующие глобальные реализации браузера не заменяются.
- До установки сборщика проверяются DOM/сетевые API и GM-функции Tampermonkey. При нехватке необходимых функций выводится сообщение, а игровые перехватчики не устанавливаются. В настройках виден результат проверки возможностей браузера.
- Права и внешние адреса не расширены: игровой сайт и локальный API, без второго SSE и автоматических игровых действий.

## Проверки 2026-10-30

| Окружение | Что проверено |
|---|---|
| Google Chrome for Testing 156.0.8078.80 + Tampermonkey 5.5.1 | Полный сценарий: установка того же файла, CSP, GM-вход/отправка, аукцион, игроки, свёрнутый HUD 0.13.0 и его навигация, отсутствие удалённых модулей и отдельных кнопок, мобильный размер окна, отключение и перезагрузка. Ошибок нет. |
| Яндекс.Браузер 26.10.0.1860 | Для 0.12.0 готовый файл и полный функциональный сценарий прошли с тестовой реализацией GM API. Запуск настоящего Tampermonkey через флаги автоматизации не состоялся ни в headless, ни в графическом режиме. Поэтому установка менеджера, реальный GM-транспорт и его изоляция в Яндексе здесь полностью не подтверждены; требуется обычная установка Tampermonkey пользователем. |
| Firefox 158.0.1 | Проверены слой совместимости и настоящий изолированный WebExtension-контекст со строгой CSP: до исправления воспроизводится Permission denied, после исправления работают fetch, ошибки сети, XHR и SSE при включённом/выключенном сборе. Полный интерфейс с установленным Firefox Tampermonkey не проверялся. |

Сценарий HUD 0.13.0 повторно проверен в настоящем Chrome/Tampermonkey; проверки Яндекса и Firefox относятся к предыдущему слою совместимости 0.12.0.

В тестах использованы синтетические игровые ответы, отдельные профили и временный тестовый API. Реальные аккаунты и игровые действия не использовались. Возможность загрузки тестового дополнения флагами автоматизации не является требованием к работе установленного userscript.

`tests/browser-smoke.cjs` принимает `CHROMIUM_PATH`, `PLAYWRIGHT_MODULE`, `TAMPERMONKEY_EXTENSION`, `TAMPERMONKEY_PROFILE`; `BROWSER_HEADLESS=0` включает графический запуск. `GM_FIXTURE=1` явно включает тестовую замену GM API и помечает результат как **не** проверку настоящего Tampermonkey. Для Firefox используется `npm run test:firefox` с отдельным geckodriver, как описано в README.
