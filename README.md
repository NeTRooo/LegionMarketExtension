# Legion Market Extension

Tampermonkey userscript для игры «Легион»: аукцион в двух режимах, досье продавца, игроки и друзья, HUD и помощник жреца поверх игры.

**Этот репозиторий содержит только браузерный клиент.** Backend, самостоятельный сайт/dashboard, базы данных, Docker и конфигурация сервера сюда не входят. Клиент использует отдельно запущенный совместимый сервер по адресу `http://127.0.0.1:4173`. Серверные расчёты, контакты и импорт требуют этого API; установка userscript сама по себе сервер не запускает.

## Установка

1. Установите Tampermonkey и разрешите пользовательские скрипты в настройках браузера.
2. [Установите userscript](https://raw.githubusercontent.com/NeTRooo/LegionMarketExtension/main/dist/ZakvielMarket.user.js). Альтернатива — импорт `dist/ZakvielMarket.user.js` через «Утилиты» Tampermonkey.
3. Перезагрузите страницу `https://play.multidonate.ru/c/…`, откройте **«⚙ Market»**, войдите в аккаунт отдельно запущенного сервера и включите сбор.

Сбор выключен при каждой загрузке страницы. Cookies и авторизация игры не собираются; пароль сайта после входа очищается, токен хранится в песочнице Tampermonkey. События личных сообщений и запросов друзей не отправляются. Данные боя жреца остаются локальными. Игровые покупки и лечение выполняются штатным интерфейсом игры.

Отправка работает, пока открыта страница игры. Очередь вкладки ограничена 500 событиями или 8 МБ; очереди закрытых вкладок восстанавливаются при следующем запуске в пределах этих лимитов, недавние пропускаются, старше семи дней удаляются. При переходе со старого расширения потребуется заново войти и настроить локальные наблюдения/HUD. Серверные данные сохраняются на сервере.

## Разработка

Node.js 22.18+ (проверено на Node.js 22).

```bash
npm ci
npm test
npm run build
npm run check:distribution
```

Результат — `dist/ZakvielMarket.user.js`. Исходники в `src/runtime`, `src/ui` и `src/tampermonkey` принадлежат только клиенту. В `tests` находятся клиентские тесты; браузерный сценарий использует синтетические ответы игры и временную заглушку API, а не сервер приложения. Для браузерного сценария нужны Playwright и распакованный Tampermonkey (`PLAYWRIGHT_MODULE`, `TAMPERMONKEY_EXTENSION`), свободный порт 4173. Проверялся Chromium + Tampermonkey 5.5.1; Firefox не проверялся.
